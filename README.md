# 이력서 빌더

학력·경력 등을 항목 단위로 추가·삭제하며 A4 이력서를 만드는 웹 앱입니다.
서버 없이 브라우저에서만 동작하고, 오프라인에서도 쓸 수 있는 PWA입니다.

**데모:** https://sohee-zoe.github.io/resume-builder/

> 데모에 들어 있는 내용(홍길동 등)은 전부 가상의 예시입니다.

## 기능

- 섹션(인적사항, 학력, 경력 등)과 항목, 행을 자유롭게 추가·삭제
- 왼쪽에서 편집하면 오른쪽 A4 미리보기에 바로 반영
- **PDF로 저장**: 브라우저 인쇄 기능으로 A4 PDF 생성
- **JSON 저장 / 불러오기**: 내용을 파일로 백업하고 다른 기기에서 복원
- **초기화**: 입력 내용을 지우고 기본 예시로 되돌림
- 홈 화면에 설치 가능 (PWA), 오프라인 동작

## 데이터 저장

입력한 내용은 **사용 중인 브라우저의 `localStorage`에만** 저장됩니다.
서버로 전송되지 않으며, 기기·브라우저마다 따로 저장되므로 동기화되지 않습니다.
다른 기기로 옮기거나 백업하려면 **JSON 저장**을 사용하세요.
브라우저 데이터를 지우면 내용도 사라집니다.

## 로컬에서 실행

빌드 과정이 없는 정적 파일입니다. 서비스 워커는 `file://`에서 동작하지 않으므로 간단한 서버로 여세요.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 화면 구조와 스타일 |
| `app.js` | 상태 관리, 편집 UI, A4 미리보기 |
| `default-data.json` | 처음 열 때·초기화할 때 불러오는 기본 예시 데이터 |
| `sw.js` | 오프라인 캐시 (네트워크 우선, 실패 시 캐시) |
| `manifest.webmanifest` | PWA 설정 |

## 배포

GitHub Pages(`main` 브랜치 루트)로 배포합니다. `main`에 push하면 자동으로 갱신됩니다.
